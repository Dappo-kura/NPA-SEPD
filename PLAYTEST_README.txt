NPA-SEPD Web Playtest

このフォルダの index.html がWeb版の入口です。
ただし Godot のWeb版は index.html を直接ダブルクリックすると動かない場合があります。

友達に遊んでもらう場合:
1. NPA-SEPD_web_playtest.zip を itch.io / Netlify / GitHub Pages などにアップロード
2. ブラウザで公開URLを開く

ローカルで確認する場合:
1. serve_local.bat を実行
2. 表示されたサーバーを閉じずに、ブラウザで http://127.0.0.1:8765/ を開く

同じフォルダ内の index.pck / index.wasm / index.js は index.html と必ず一緒に置いてください。
